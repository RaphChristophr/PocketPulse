# Dokumentasi PocketPulse

PocketPulse menggantikan catatan keuangan di Notes dengan pencatatan cepat dari HP dan ringkasan yang terhitung otomatis. Aplikasi dibangun sebagai **PWA mobile-first untuk satu pengguna**, dengan akses dari layar utama HP, pencatatan offline, dan backup yang bisa dipulihkan.

- [PRD](PRD.md) menjelaskan kebutuhan, alur pengguna, dan aturan produk.
- [Scope MVP](MVP_SCOPE.md) menetapkan isi rilis pertama dan kriteria siap pakai.
- [Implementation Plan](IMPLEMENTATION_PLAN.md) mengurutkan tahap pengembangan dan pengujian.
- [Wireframe](WIREFRAMES.md) menunjukkan layar utama, pencatatan, dan pengaturan.
- [Data Model](DATA_MODEL.md) mendefinisikan struktur data dan aturan perhitungan.
- [Arsitektur dan keputusan build](ARCHITECTURE.md) menjelaskan pilihan penyimpanan, struktur folder, keputusan build atau fork, dan jalur integrasi spreadsheet.
- [Backlog](BACKLOG.md) mencatat fitur dan perbaikan yang direncanakan berikutnya.
- [Checklist setelah perubahan dev](DEV_RELEASE_CHECKLIST.md) menjelaskan langkah GitHub, Supabase, dan Vercel setelah pekerjaan siap.

Mulai dari PRD dan Scope MVP untuk memeriksa alurnya. Gunakan Implementation Plan, Data Model, dan Wireframe ketika mulai mengembangkan aplikasi.
